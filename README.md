# Практическое знакомство с Java

Персональный тренажёр: ИИ-тренер создаёт задания и JUnit-тесты, а затем проверяет решение локально и после push через GitHub Actions.

## Как начать

Напиши агенту: **«Начнём»**.

Дальше агент создаст условие в `tasks/active/`, заготовку решения в `src/main/java/` и тесты в `src/test/java/`. После решения напиши: **«Проверь задание»**.

## Команды

- `Начнём` — заполнить профиль и получить первое задание.
- `Проверь задание` — запустить тесты и получить обратную связь.
- `Ещё задание` — новый вариант текущей темы.
- `Следующая тема` или `Тема №X` — сменить тему.
- `Подсказка`, `Упрости`, `Объясни ...` — получить помощь.
- `Покажи прогресс` — показать статистику обучения.

## Проверка

Локально:

```shell
.\mvnw.cmd test
```

В Linux/macOS: `./mvnw test`.

После push тесты автоматически запускаются в GitHub Actions.

## Текущее задание: профиль игрового персонажа

Напиши программу, которая через `Scanner` читает:

1. имя игрока — целую строку;
2. класс персонажа — целую строку;
3. уровень персонажа — целое число.

Выведи результат строго в таком формате:

```text
Игрок: <имя>
Класс: <класс>
Уровень: <уровень>
Готов к приключению!
```

Имя и класс могут содержать пробелы. Уровень — число от 1 до 100. Не выводи приглашения наподобие `Введите имя`.

- Решение: `src/main/java/learning/topic01/task01/Solution.java`
- Полное условие: `tasks/active/task_01_01_game_profile/README.md`
- Проверка: `.\mvnw.cmd test`
