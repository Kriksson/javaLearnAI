# Задача №39 — Игроки с заданными расходами

**Сложность:** SQL, начинающий уровень

**Закрепляем:** `JOIN`, `GROUP BY`, агрегаты, сортировку.

**Новое:** `HAVING` — фильтр для уже сгруппированных данных.

Для магазина нужен список игроков, потративших не меньше 100.00. В `src/main/resources/learning/task039/query.sql` напиши один SQL-запрос.

## Материал для изучения

В запросе с группировкой сначала выбираются строки и соединяются таблицы, затем строки объединяются в группы, после чего вычисляются агрегаты. Условия для исходных строк задаёт `WHERE`, а условия для готовых групп — `HAVING`.

```sql
SELECT category_id, SUM(amount) AS total_amount
FROM payments
GROUP BY category_id
HAVING SUM(amount) >= 100
ORDER BY total_amount DESC;
```

`WHERE` выполняется до группировки, поэтому им нельзя отфильтровать результат `SUM`. Для этого и используют `HAVING`. Условие можно написать с агрегатным выражением, как в примере.

## Что сделать

Выведи две колонки:

- `nickname` — никнейм игрока;
- `total_spent` — сумма его заказов.

Покажи игроков, чья общая сумма заказов не меньше 100.00 включительно. Сначала больший расход; при равной сумме — никнейм по возрастанию. Игроки без заказов и те, кто потратил меньше порога, в отчёт не входят.
