# Тег игрового персонажа

- Тема: 2. Строки, методы и классы
- Сложность: лёгкая

## Условие

Реализуй метод, который создаёт тег игрового персонажа из ника и класса.

Метод должен:

1. убрать пробелы в начале и конце ника и класса;
2. преобразовать класс персонажа в верхний регистр;
3. вернуть строку в формате `[КЛАСС] Ник`;
4. вернуть `Некорректные данные`, если ник или класс после удаления пробелов пуст.

## Сигнатура

```java
public static String createPlayerTag(String nickname, String characterClass)
```

Не изменяй имя класса, пакета и метода.

## Примеры

```text
createPlayerTag("Kirill", "mage") → "[MAGE] Kirill"
createPlayerTag("  Тень  ", "  лучник ") → "[ЛУЧНИК] Тень"
createPlayerTag("   ", "warrior") → "Некорректные данные"
```

## Ограничения

- Аргументы не равны `null`.
- Регистр ника нужно сохранить.
- Лишних пробелов в результате быть не должно.
- Используй методы класса `String`.

## Критерии готовности

- Метод возвращает тег в точном формате.
- Пустые после очистки строки обрабатываются отдельно.
- Все тесты проходят.
