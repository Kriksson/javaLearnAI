# Игровой идентификатор

- Задача: №3
- Навыки: `substring`, проверки длины и композиция методов
- Сложность: средняя

## Условие

Создай генератор игрового идентификатора из ника игрока и названия игры.

### Код игры

Метод `createGameCode` должен:

1. убрать пробелы в начале и конце названия;
2. перевести название в верхний регистр;
3. вернуть первые три символа;
4. вернуть всю строку, если в ней меньше трёх символов;
5. вернуть пустую строку, если после очистки название пусто.

### Идентификатор игрока

Метод `createPlayerId` должен:

1. убрать пробелы по краям ника и названия игры;
2. вернуть `Некорректные данные`, если одна из строк стала пустой;
3. перевести ник в верхний регистр;
4. заменить каждый пробел в нике символом `_`;
5. получить код игры через `createGameCode`;
6. вернуть результат в формате `<КОД ИГРЫ>-<НИК>`.

## Сигнатуры

```java
public static String createGameCode(String gameTitle)
public static String createPlayerId(String nickname, String gameTitle)
```

Не изменяй пакет, класс и сигнатуры методов.

## Примеры

```text
createPlayerId("Shadow Player", "Minecraft") → "MIN-SHADOW_PLAYER"
createPlayerId("  Тёмный Рыцарь  ", "Dota 2") → "DOT-ТЁМНЫЙ_РЫЦАРЬ"
createPlayerId("Kirill", " CS ") → "CS-KIRILL"
```

## Ограничения

- Аргументы не равны `null`.
- Регистр результата должен точно соответствовать условию.
- Используй методы `String`: `trim`, `toUpperCase`, `replace`, `substring` и `length`.
- Не используй циклы — они понадобятся в следующих задачах.

## Критерии готовности

- Оба метода работают независимо.
- Короткое название игры не вызывает ошибку.
- Пустые строки обрабатываются отдельно.
- Все тесты проходят.
