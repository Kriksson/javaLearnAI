# Профиль игрового персонажа

- Тема: 1. `Scanner` и вывод
- Сложность: лёгкая

## Условие

Напиши консольную программу, которая читает три значения:

1. имя игрока — целая строка;
2. класс персонажа — целая строка;
3. уровень персонажа — целое число.

После этого программа должна вывести карточку персонажа строго в таком формате:

```text
Игрок: <имя>
Класс: <класс>
Уровень: <уровень>
Готов к приключению!
```

Не выводи приглашения вроде `Введите имя` — тесты ожидают только карточку.

## Сигнатура

Класс и метод уже созданы:

```java
public class Solution {
    public static void main(String[] args)
}
```

## Примеры

Ввод:

```text
Kirill
Warrior
12
```

Вывод:

```text
Игрок: Kirill
Класс: Warrior
Уровень: 12
Готов к приключению!
```

Ввод:

```text
Тёмный рыцарь
Маг огня
1
```

Вывод:

```text
Игрок: Тёмный рыцарь
Класс: Маг огня
Уровень: 1
Готов к приключению!
```

Ввод:

```text
Player One
Space Ranger
99
```

Вывод:

```text
Игрок: Player One
Класс: Space Ranger
Уровень: 99
Готов к приключению!
```

## Ограничения

- Имя и класс могут содержать пробелы.
- Уровень — целое число от 1 до 100.
- Формат и порядок строк должны совпадать с условием.

## Критерии готовности

- Все три значения читаются через `Scanner`.
- Вывод содержит ровно четыре требуемые строки.
- Команда `.\mvnw.cmd test` завершается успешно.
