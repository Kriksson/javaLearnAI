# Задача №37 — Отчёты по заказам игроков

**Сложность:** начинающий SQL

**Закрепляем:** таблицы, типы и ограничения.

**Новое:** `SELECT`, `WHERE`, `ORDER BY`, `SUM`, `GROUP BY`.

Напиши SQL-запросы для готовых таблиц `players` и `player_orders`. Тесты сами создадут таблицы и заполнят их данными.

## Материал для изучения

`SELECT` читает данные, не меняя их. Общая форма запроса:

```sql
SELECT поле_1, поле_2
FROM таблица
WHERE условие
ORDER BY поле_1 DESC, поле_2 ASC;
```

- `WHERE` оставляет только строки, подходящие под условие; для сравнения используются `=`, `>=`, `<=`.
- `ASC` сортирует по возрастанию, `DESC` — по убыванию. Второе поле сортировки решает, что делать при равенстве первого.
- `SUM(столбец)` складывает значения нескольких строк. Если одновременно выбираешь обычное поле и агрегат, обычное поле нужно указать после `GROUP BY`.

```sql
SELECT category_id, SUM(amount) AS total_amount
FROM payments
GROUP BY category_id
ORDER BY total_amount DESC;
```

`AS total_amount` задаёт имя вычисленному столбцу. Это не изменяет таблицу.

## Что сделать

В `src/main/resources/learning/task037/queries.sql` напиши ровно три `SELECT`-запроса. Разделяй их `;` и расположи в указанном порядке.

1. Выведи `nickname` и `level` игроков уровня 40 и выше. Сначала больший уровень, затем никнейм по возрастанию.
